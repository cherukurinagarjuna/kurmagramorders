## 2. Screen 2: Catalog Page (`/shop`)

### Mobile Viewport (360px)
- **Top Sticky Search & Filter Bar:** Search input with brass magnifying icon + horizontal scrolling natural-dye swatch chips (`అన్నీ`, `సంరక్షణ`, `గో ఉత్పత్తులు`, `వ్యవసాయం`, `ధాన్యాలు`, `నూనెలు`).
- **Product Stack:** 1-column kraft paper cards with 2px iron-black illustrations, dual-unit toggle pill (`[250g] [500g]`), live price, and tactile underline action: `+ కార్ట్లో చేర్చు`.
- **Bottom Summary Pill:** Quick floating cart preview showing current total and checkout shortcut.

### Desktop Viewport (1440px)
- **Left Sidebar Filter (280px):** Category tree with botanical dye indicators, price range filter, organic certification toggle, and FSSAI statutory reminder.
- **Right Product Grid (3 Columns):** Asymmetric spacing, kraft cards with brass framing, unit pill selectors, and immediate add-to-cart with temple-bell feedback.

## 3. Screen 3: Product Detail Page (`/product/[id]`)

### Mobile Viewport (360px)
- **Image Carousel / Stage:** Real preparation photo with toggle to view 2px iron-black Kalamkari botanical drawing.
- **Editorial Header:** Product Telugu title, traditional usage tag, FSSAI indicator.
- **Unit Selector Matrix:** Accessible radio buttons (`500ml - ₹220` vs `1L - ₹420`).
- **Sticky Bottom Action Bar (48px touch target):** Price total + `కార్ట్లో చేర్చు` (Add to Cart) + Direct WhatsApp inquiry button.
- **Traditional Preparation Story:** Detailed description of cold wood-churning, herbal decoction, or Vedic method.

### Desktop Viewport (1440px)
- **Two-Column Editorial Grid (50% / 50%):**
  - Left: Sticky photo gallery with high-resolution farm stills and botanical diagram.
  - Right: Editorial typography, package size cards, Vedic rationale, ingredients list, FSSAI license notice, direct-UPI badge, and related preparations.

## 4. Screen 4: Direct-UPI Checkout (`/checkout`)

### Mobile Viewport (360px)
- **Step 1: Delivery Details:** Name, WhatsApp phone number, full village/town address, PIN code.
- **Step 2: Payment Execution:**
  - Active button: `[📲 UPI యాప్ ద్వారా చెల్లించండి]` -> triggers `upi://pay?pa=kurmagramvv@upi&pn=Kurmagram...`.
  - Fallback option: Display QR code for scan from another phone.
- **Step 3: UTR Verification:** 12-digit transaction ID input field with paste button.
- **Step 4: Confirmation:** `[💬 WhatsApp లో ఆర్డర్ పంపండి]` -> launches WhatsApp with formatted order dispatch.

### Desktop Viewport (1440px)
- **Split Screen:**
  - Left: Customer shipping address form & order itemization summary.
  - Right (Sticky Payment Box):
    - In-browser generated NPCI-compliant QR code (Level M, 240×240px) with central Kurma seal.
    - Prominent Trust UPI ID: `kurmagramvv@upi` with 1-click copy button.
    - 12-digit UTR input + "Confirm Order via WhatsApp" CTA.
    - Live zero-fee transparency banner (`₹0 Payment Processing Fees`).
